1. Documents Audited:

2. Description and Scope:
   These documents describe the earlier conceptual toy 5-qubit simulation model
   utilizing fixed weighting parameters (alpha = 0.6, beta = 0.4, with reported
   toy fidelities such as 0.974 vs 0.968).

3. Status & Hardware Disclaimers:
   - The findings in these early PDF and PPTX files are NOT supported by this
     repository's live Heron r2 hardware results (ibm_marrakesh).
   - In live hardware execution, thermal ESP does not demonstrate statistically
     significant gains over plain ESP or Qiskit compiler baselines under nominal
     operating temperatures.
   - Per project governance rules, the original PDF and PPTX files are preserved
     unedited for historical archival purposes, but must not be cited as empirical
     evidence for hardware performance.
