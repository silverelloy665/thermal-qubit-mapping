1. CORE RESEARCH HYPOTHESIS & QUESTION
--------------------------------------------------------------------------------
Research Question:
On a real IBM Heron processor (ibm_marrakesh), does a circuit layout containing a
qubit with high excess excited-state population perform worse than the best layout
that avoids it, within the same local spatial region of the device?

Metric Labeling:
Excess excited-state population is strictly labeled and quantified as:
  "excess P(1|0) over calibrated readout error"
defined as:
  excess_p1 = P(1|0) - readout_error
where P(1|0) is the ground-state reset failure probability measured by unexcited
readout, and readout_error is the independently calibrated measurement error.


2. HOT QUBIT & CANDIDATE REGION IDENTIFICATION
--------------------------------------------------------------------------------
Hot Qubit Inclusion Criteria:
  - excess P(1|0) > 0.05
  - readout_error <= 0.20 (to exclude pure readout failures, e.g. qubits 94 and 130)

Top 3 Identified Hot Qubits on ibm_marrakesh:
  - Region 1 (h = 125): excess P(1|0) = 0.4117, readout_error = 0.0096, measured P(1) = 0.4214
  - Region 2 (h = 22) : excess P(1|0) = 0.1907, readout_error = 0.0120, measured P(1) = 0.2026
  - Region 3 (h = 26) : excess P(1|0) = 0.1097, readout_error = 0.0426, measured P(1) = 0.1523


3. TOPOLOGICAL NEIGHBORHOOD RADIUS & SUBGRAPH FREEDOM (RADIUS 2 vs RADIUS 4)
--------------------------------------------------------------------------------
Graph Radius 2 Limitation (Why Radius 2 Has No CLEAN Subgraph):
  In the IBM Heron heavy-hex architecture (maximum vertex degree 3, girth 6), any
  induced subgraph within graph distance <= 2 of a center node h contains at most
  7 qubits and has tree topology.
  Removing center node h partitions the remaining vertices into disjoint components
  of size at most 3.
  Therefore, it is mathematically impossible for any connected 5-qubit subgraph
  avoiding h to exist within graph distance <= 2.

Empirical Subgraph Counts at Radius <= 2:
  - Region 1 (h=125): 7 qubits total | HOT 5q subgraphs = 6  | CLEAN 5q subgraphs = 0
  - Region 2 (h=22) : 7 qubits total | HOT 5q subgraphs = 6  | CLEAN 5q subgraphs = 0
  - Region 3 (h=26) : 7 qubits total | HOT 5q subgraphs = 6  | CLEAN 5q subgraphs = 0
  Result: 0 of 3 regions possess a clean connected 5-qubit layout at radius 2.

Radius <= 4 Expansion (Minimal Connected Neighborhood):
  Expanding to graph distance <= 4 provides the minimal local neighborhood that
  admits both HOT and CLEAN connected 5-qubit subgraphs:
  - Region 1 (h=125): 19 qubits total | HOT 5q subgraphs = 27 | CLEAN 5q subgraphs = 9
  - Region 2 (h=22) : 16 qubits total | HOT 5q subgraphs = 18 | CLEAN 5q subgraphs = 3
  - Region 3 (h=26) : 19 qubits total | HOT 5q subgraphs = 22 | CLEAN 5q subgraphs = 10

5. CONFOUNDING EXCLUSION CRITERION & DECISION RULE
--------------------------------------------------------------------------------
Confounding Exclusion Criterion:
  In physical layouts, two-qubit gate count differences can significantly overpower
  thermal dissipation effects. Therefore, any test cell where:
    |native 2Q difference HOT vs CLEAN| = |clean_2q - hot_2q| > 4
  is pre-registered as "CONFOUNDED". Confounded cells are reported in all tables
  for transparency, but are strictly EXCLUDED from contributing to the confirmation
  decision rule.

Pre-Transpilation Confounding Classification by Cell:
  - Region 1:
      ghz   : hot_2q=4, clean_2q=8  -> diff = +4  (<= 4, VALID / NOT CONFOUNDED)
      bv    : hot_2q=8, clean_2q=8  -> diff =  0  (<= 4, VALID / NOT CONFOUNDED)
      mirror: hot_2q=51, clean_2q=50 -> diff = -1 (<= 4, VALID / NOT CONFOUNDED)
  - Region 2:
      ghz   : hot_2q=5, clean_2q=4  -> diff = -1  (<= 4, VALID / NOT CONFOUNDED)
      bv    : hot_2q=2, clean_2q=8  -> diff = +6  (> 4, CONFOUNDED - EXCLUDED)
      mirror: hot_2q=54, clean_2q=49 -> diff = -5  (> 4, CONFOUNDED - EXCLUDED)
  - Region 3:
      ghz   : hot_2q=4, clean_2q=4  -> diff =  0  (<= 4, VALID / NOT CONFOUNDED)
      bv    : hot_2q=5, clean_2q=8  -> diff = +3  (<= 4, VALID / NOT CONFOUNDED)
      mirror: hot_2q=54, clean_2q=42 -> diff = -12 (> 4, CONFOUNDED - EXCLUDED)

Pre-Registered Decision Rule:
  "Hot-spot penalty confirmed" for benchmark B only if:
  1. Among VALID (non-confounded, |diff_2q| <= 4) regions, the pooled difference:
       success(CLEAN) - success(HOT)
     has a Newcombe hybrid score 95% confidence interval lower bound > 0.
  2. The point estimate difference is >= +0.5 pt.
  3. These criteria are satisfied in at least 2 valid candidate regions (>= 2 regions).

Regional Feasibility by Benchmark:

  - Mirror-5: 1 valid region (R1). INELIGIBLE for confirmation (cannot achieve >= 2
