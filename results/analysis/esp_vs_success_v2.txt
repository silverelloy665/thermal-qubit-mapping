6. METHODOLOGICAL OBSERVATIONS & LIMITATIONS
------------------------------------------------------------------------------------
Observations (not causal claims):
  1. Coarse Separation:
     Calibrated ESP cleanly separates poor (Random) from good (compiler) layouts across
     success_prob benchmarks (pooled r = +0.9294, rho = +0.7824, n = 13).
     However, this reflects coarse separation only; one random layout; one calibration day;
     and benchmarks have different baselines.
  2. Within-Benchmark Ranking:
     When omitting the single Random layout, correlation across compiler layouts is:
     leave-random-out r = +0.8616, rho = +0.7378 (n = 10).
     Within individual benchmarks (n <= 5 distinct circuits each), ESP did not reliably
     rank compiler layouts. For example:
       - GHZ (n = 4): ESP tracks closely (r = +0.9964, rho = +0.8000).
       - BV (n = 4): Negative correlation (r = -0.9885, rho = -0.9487).
         In BV, Random ESP is 0.927 with success 0.8635; ESP layout ESP is 0.941 with
         success 0.8632; L1/L3 ESP is 0.866 with success ~0.914. No causal explanation
         is asserted; this is noted strictly as an empirical observation.
       - Mirror (n = 5): Pearson r = +0.9331, but rank ordering is weak (rho = +0.3591).
       - QFT (n = 4): Evaluated via Hellinger fidelity (r = +0.7100, rho = +0.2000);
         fidelity is not pooled with success probability.
  3. Limitations:
     - Single calibration day (2026-10-09T00:18:39+05:30) on ibm_marrakesh.
     - Random baseline is a single layout ([80, 61, 62, 76, 81]) from a single draw.
     - Per-benchmark sample sizes are n = 4 (GHZ, BV, QFT) and n = 5 (Mirror);
       confidence intervals and p-values are not informative at n <= 5.
