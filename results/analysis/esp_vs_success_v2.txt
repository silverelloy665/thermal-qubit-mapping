6. METHODOLOGICAL OBSERVATIONS & LIMITATIONS
------------------------------------------------------------------------------------
Observations (not causal claims):
  1. Coarse Separation:
     Calibrated ESP cleanly separates poor (Random) from good (compiler) layouts across
     success_prob benchmarks (pooled r = +0.9431, rho = +0.7741, n = 12).
  2. Within-Benchmark Ranking:
     When omitting the single Random layout, correlation across compiler layouts drops
     (leave-random-out r = +0.8494, rho = +0.6946, n = 9).
     Within individual benchmarks (n = 4 distinct circuits each), ESP did not reliably
     rank layouts. For example:
       - GHZ: ESP tracks closely (r = +0.9964, rho = +0.8000).
       - BV: Negative correlation (r = -0.9885, rho = -0.9487).
         In BV, Random ESP is 0.927 with success 0.8635; ESP layout ESP is 0.941 with
         success 0.8632; L1/L3 ESP is 0.866 with success ~0.910. No causal explanation
         is asserted; this is noted strictly as an empirical observation.
       - Mirror: Pearson r = +0.9535, but rank ordering is weak (rho = +0.4000).
       - QFT: Measured via Hellinger fidelity (n = 4; r = +0.7100, rho = +0.2000);
         fidelity is not pooled with success probability.
  3. Limitations:
     - Single calibration day (2026-10-09T00:18:39+05:30) on ibm_marrakesh.
     - Random baseline is a single layout ([80, 61, 62, 76, 81]) from a single draw.
     - Sample size is limited (n = 4 distinct circuits per benchmark).
